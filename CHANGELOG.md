# Changelog

## 1.0.0 (2026-11-09)

First release.

- 30 numbered checks in 3 groups of 10: website and marketing pages, data vendors and lead lists, outreach and automation. Each has what to look at, how to check it, a pass or fail test, the fix and the source.
- Vendor due diligence questionnaire for data brokers, with 30 questions and contract wording to discuss with a lawyer.
- Website wording fix guide with 24 before and after examples, all synthetic.
- Guide for a restricted account, and a write up of the Artisan case as told by its CEO to TechCrunch.
- Paste in quick start prompt, a Claude Code skill and a `/linkedin-audit` command.
- 3 standard library tools: `scan_site.py`, `lead_list_check.py`, `score_audit.py`.
- Scored audit sheet, synthetic sample data and `tests/check_kit.py`, run by GitHub Actions.
- LinkedIn's pages and every other source read on 2026-11-09.
